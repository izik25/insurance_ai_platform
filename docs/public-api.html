Public API — קריאת נספחים והשוואות בין חברות

API ציבורי, ללא אימות (unauthenticated), לקריאה בלבד. מיועד לצד שלישי חיצוני שרוצה לשלוף מידע על נספח ביטוח לפי חברה + מספר נספח, ולראות לאילו נספחים אצל חברות אחרות הוא הותאם.

Base URL (production): http://191.218.162.211/public/v1
זיהוי: כל בקשה מזוהה לפי company_id (למשל migdal, phoenix, clal, menorah, directinsurance) + appendix_number (מספר הנספח כפי שמופיע אצל החברה) — לא לפי מזהה פנימי של המערכת.

קידוד: appendix_number יכול להכיל תו "/" בתוכו (למשל "09/2023") — יש ל-URL-encode כל segment בנפרד (לא את המחרוזת השלמה כמקשה אחת).

1. קריאת מסמך/נספח לפי מספר נספח

GET /public/v1/companies/{company_id}/appendices/{appendix_number}

מחזיר את כל השדות שחולצו מהנספח: סוג/שם כיסוי, תנאי זכאות, סכומי ביטוח, תקופת אכשרה/המתנה, חריגים, טבלאות ועוד.

{ "detail": "No appendix found for this company/number" }

הורדת הקובץ המקורי (PDF)

GET /public/v1/companies/{company_id}/appendices/{appendix_number}/file?download=true
  • download=true → מוריד כקובץ מצורף
  • בלי הפרמטר → נפתח inline בדפדפן
  • שגיאות: 404 אם אין נספח כזה, או אם הקובץ לא קיים על הדיסק

2. קריאת השוואות בין נספחים (cross-company matching)

GET /public/v1/companies/{company_id}/appendices/{appendix_number}/matches

מחזיר את כל הנספחים אצל חברות אחרות שהמערכת זיהתה כמתארים כיסוי דומה לנספח הזה, עם ציון דמיון וסטטוס בדיקה.

פרמטר אופציונלי

  • status סינון לפי סטטוס בדיקה: auto_confirmed pending_review confirmed rejected

דוגמה

# curl
curl "http://191.218.162.211/public/v1/companies/migdal/appendices/123/matches?status=auto_confirmed"

תגובה — 200 OK

[
  {
    "company_id": "phoenix",

    "appendix_name": "כיסוי אשפוז מורחב",
    "domain": "health",
    "similarity_score": 0.94,
    "status": "auto_confirmed"
  },
  {
    "company_id": "clal",
    "appendix_number": ["45-B"],
    "appendix_name": "אשפוז כללי",
    "domain": "health",

מערך ריק [] — נספח קיים אבל אין לו (עדיין) שום התאמה שתואמת את הסינון.
